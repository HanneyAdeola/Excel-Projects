# 📊 Adventure Works Sales Analysis (Excel Dashboard)

## 📌 Project Overview
This project presents an interactive **Sales Analysis Dashboard for Adventure Works**, built using **Microsoft Excel**.  
The dashboard provides insights into sales performance, profitability, transaction trends, and time-based patterns to support data-driven business decisions.

The analysis focuses on key financial metrics such as **revenue, cost, profit, profit margin, and transaction volume**, with performance evaluated across **years, months, weekdays, quarters, and regions**.

---

## 🎯 Objectives
The main objectives of this analysis are to:
- Evaluate overall sales and profitability performance
- Track changes in revenue, cost, and profit over time
- Analyze transaction trends across years
- Identify high-performing months, weekdays, and quarters
- Compare weekday and weekend contribution to profit
- Enable regional performance analysis using interactive filters

---

## 🧰 Tools Used
- **Microsoft Excel**
  - Pivot Tables
  - Pivot Charts
  - Slicers and Timelines
  - Calculated fields and measures
- **Excel Data Cleaning and Transformation**

---

## 📊 Dataset Description
The dataset contains transactional sales records with the following attributes:
- Sales quantity
- Cost of Goods Sold (COGS)
- Revenue
- Profit
- Transaction count
- Date (year, month, weekday)
- Country / Region

The data spans multiple years (**2005–2008**) and covers several international markets.

---

## 📈 Key Performance Indicators (KPIs)
- **Total Quantity Sold:** 23.58K  
- **Total COGS:** $6.04M  
- **Total Revenue:** $10.27M  
- **Total Profit:** $4.23M  
- **Profit Margin:** 41.2%  
- **Total Transactions:** 2.29K  

These KPIs provide a high-level summary of overall business performance.

---

## 🔍 Key Insights

### Sales & Profitability
- Profit margin improved to **41.2%**
- Transaction volume increased by **40.54%**
- Quantity sold increased by **25.31%**
- Slight declines observed in revenue and profit, indicating efficiency improvements despite stable sales

### Monthly Performance
- In 2007, **September, November, and December** collectively contributed **40.4%** of total profit
- **December** recorded the highest monthly profit
- Early months show comparatively lower profit levels

### Weekday vs Weekend Analysis
- **Weekdays account for 69.1%** of total profit ($2.93M)
- **Weekends contribute 30.9%** ($1.31M)
- Selected weekdays contribute **46.0%** of total profit
- Highest profit days include Sunday, Tuesday, and Saturday

### Quarterly Performance
- **Q1:** $589.75K (14%)
- **Q2:** $816.87K (19%)
- **Q3:** $1.19M (28%)
- **Q4:** $1.64M (39%)

📌 Quarter 4 is the most profitable period, contributing nearly 40% of total profit.
